# ADR 0008: ШІ-оцінювання письмових відповідей — окрема Lambda поза VPC

- **Статус:** Прийнято, 2026-11-13
- **Пов'язане:** [PROJECT.md → «ШІ-оцінювач»](../../PROJECT.md#ші-оцінювач-apiinternalgrading), `backend/app/grader/`, `backend/app/services/grading.py`

## Контекст

Тести містять письмові відповіді, які мають перевірятися автоматично, а за потреби — репетитором. Обмеження проєкту — **нічого не платити за інфраструктуру**:

- API Lambda стоїть у VPC без NAT і без VPC endpoints, тож до Bedrock вона не дістанеться.
- NAT Gateway коштує ~$33/міс, interface endpoint `bedrock-runtime` — ~$7/міс за AZ. Безкоштовного рівня в них немає.
- Безкоштовного API для Claude немає. На акаунті є кредити AWS ($77 на 2026-11-13), але чи покривають вони Claude на Bedrock (продається через AWS Marketplace), підтверджено не було.

## Рішення

1. **Окрема Lambda оцінювача з того самого образу, поза VPC.** Вона має інтернет без NAT і бази не бачить. Модуль `app.grader` не імпортує `app.db` і SQLAlchemy, і це перевіряє тест.
2. **Обмін через API.** Оцінювач викликає `/api/internal/grading` на публічному function URL з заголовком `X-Grader-Token`:
   - `claim` орендує найстаріші здані тести на 5 хвилин (`FOR UPDATE SKIP LOCKED`);
   - `result` записує бали;
   - `failed` передає тест репетитору.
3. **Запуск.** EventBridge Scheduler раз на хвилину; фронтенд може ще й «смикнути» оцінювача одразу після здачі.
4. **Модель — Claude Haiku 5.5** (`anthropic.claude-haiku-5-5`) через `AnthropicBedrockMantle`. Її обрала власниця проєкту замість Opus 5.5 через вартість: приблизно 0.05 цента проти 2 центів за тест. Відповідь приходить через structured output; бали обрізаються до `0..max`.
5. **Захист від витрат:**
   - оренда, щоб два запуски не платили за той самий тест;
   - **жодних повторів**: будь-яка помилка чи відмова одразу передає тест репетитору;
   - бюджет $1 на Bedrock і Marketplace з алертом;
   - вимикачі `AI_GRADER=off` (API) і `GRADER=off` (Lambda).
6. **Захист від prompt injection.** Текст учня екранується, а системний промпт оголошує вміст `<student_answer>` лише даними. Репетитор може змінити будь-який бал.

## Альтернативи

- **NAT або VPC endpoint** — простіше в коді, але це постійні щомісячні витрати.
- **API Lambda поза VPC** з публічною Aurora — відкривати базу в інтернет неприйнятно.
- **Aurora Data API для оцінювача** — він ходив би в базу без VPC, але це другий спосіб доступу до даних, окремі права і SQL поза моделями.
- **Оцінювання у браузері** — клієнт міг би підробити бали, а еталонні відповіді потрапили б до учня.

## Наслідки

- Бали за письмові відповіді з'являються із затримкою до хвилини (або одразу, якщо фронтенд «смикне» оцінювача).
- Внутрішні ендпоінти доступні з інтернету й захищені лише секретом. Його треба тримати в state HCP і в змінних обох Lambda й не логувати.
- Локально оцінювач — `make grade` з `FakeGrader`, а Bedrock — за бажанням (`GRADER=bedrock`).
