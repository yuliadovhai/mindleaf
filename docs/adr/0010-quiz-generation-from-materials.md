# ADR 0010: Тести з матеріалів генерує ШІ-воркер, результат — лише чернетка

- **Статус:** Прийнято, 2026-11-13
- **Пов'язане:** [ADR 0008](0008-ai-grading-outside-the-vpc.md), [PROJECT.md → «Генерація тестів»](../../PROJECT.md#генерація-тестів-apiinternalgeneration), `backend/app/services/generation.py`, `backend/app/grader/generators.py`

## Контекст

Репетитор завантажує матеріали (PDF, фото, текст) і хоче отримувати з них тести, а також додавати тести й ДЗ сам. Обмеження ті самі, що в ADR 0008:

- API Lambda не має доступу до Bedrock;
- інфраструктура не повинна мати погодинних платежів;
- кожен виклик моделі коштує грошей.

Згенерований тест може містити помилки: неправильну «правильну» відповідь або питання поза матеріалом. Учні не повинні їх побачити.

## Рішення

1. **Генерація — це черга** (`quiz_generations`). Репетитор створює запит. Обробляє його **той самий воркер поза VPC**, що оцінює письмові відповіді, за той самий запуск раз на хвилину. Доступ до черги — через `/api/internal/generation` з тим самим токеном. Нової інфраструктури немає.
2. **Матеріал воркер отримує за підписаним посиланням** від API: прямо з S3 у хмарі або з `/api/files` локально. API Lambda файл не читає (без мережі вона й не змогла б), а воркеру не потрібні права на S3.
3. **Claude Haiku 5.5 читає матеріал напряму:** PDF — блоком `document`, фото — блоком `image`, текст — текстом. Тому підтримуються лише PDF, JPEG, PNG, TXT і MD. Word треба зберегти як PDF, і так обійтися без додаткових бібліотек.
4. **Результат — лише чернетка** (`quizzes.status = draft`). API перевіряє її тими самими правилами, що й тест репетитора. Призначити чернетку не можна (`409 quiz_is_draft`), доки репетитор її не перегляне, не виправить і не опублікує (`POST /api/quizzes/{id}/publish`).
5. **Захист від витрат:**
   - щонайбільше 3 незавершені генерації на репетитора;
   - оренда на 5 хвилин, щоб два запуски не генерували одне й те саме;
   - жодних повторів після помилки;
   - питання, що порушують правила, відкидаються, а не перезапитуються;
   - лишаються спільні з оцінювачем бюджет $1 і вимикач `GRADER=off`.
6. **Захист від prompt injection.** Матеріал і побажання репетитора екрануються, а системний промпт оголошує їх лише даними.

## Альтернативи

- **Генерувати одразу в запиті репетитора** — неможливо з API Lambda без мережі. До того ж запит тривав би до хвилини.
- **Одразу готовий тест** — швидше, але помилки ШІ потрапили б до учнів. Власниця проєкту обрала чернетку.
- **Окрема Lambda для генерації** — ще один ресурс і ще один розклад, а користі немає: воркер уже існує й має всі потрібні дозволи.
- **Підтримка .docx** — потребує розбору на бекенді (python-docx) і втрачає картинки. Відкладено.

## Наслідки

- Чернетка з'являється приблизно за хвилину. Сторінка «Матеріали» поки чекає, оновлює себе кожні 10 секунд.
- Одна генерація зі звичайного PDF коштує частки цента на Haiku 5.5. Модель можна змінити через `GRADER_MODEL`.
- Видалення матеріалу не видаляє вже створені з нього тести: `source_material_id` стає null.
